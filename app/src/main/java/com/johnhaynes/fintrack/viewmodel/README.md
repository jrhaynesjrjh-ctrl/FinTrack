FinTrack
Project Overview
FinTrack is a personal finance tracking mobile application developed for the SDC480 Capstone Project. The application allows users to log in, manage transactions, view financial summaries, and search transaction records using a simple and intuitive Android interface.

Project Summary
FinTrack is a mobile finance management application that demonstrates Android development concepts including Jetpack Compose, navigation, state management, user authentication, and financial data presentation. Users can navigate between multiple screens, view transaction summaries, search transaction records, and manage account information. The application showcases mobile development skills, UI design, application structure, and software engineering best practices.
